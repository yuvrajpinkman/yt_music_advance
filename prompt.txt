Implement the following functionalities using Rust and standard Tauri configurations:

1. **Window Management & Minimize to Tray (Background Process):**
   - Intercept the window close event (clicking the `X` button). Instead of quitting the app, prevent the default close and just hide the window.

2. **System Tray Options:**
   - Create a system tray with "Show" and "Quit" menu items.
   - If the user double-clicks the tray icon or clicks the "Show" menu item, unhide and focus the main window.
   - If the user clicks "Quit", terminate the application gracefully.
   - If one instance of App is running prevent another instance from running.

3. **Now Playing Desktop Notifications:**
   - Add the `tauri-plugin-notification` to the project.
   - Create a Tauri command in Rust called `notify_song` that takes a `title` and `artist` as arguments and triggers a system notification saying "Now Playing: [Artist] - [Title]".
   - Automatically inject a JavaScript script into the YouTube Music webview (using Tauri's window `initialization_script` feature) that polls for DOM elements containing the currently playing song's title and artist. When a track change is detected, it should invoke the `notify_song` Tauri command.

4. **Windows Compatibility:**
   - Ensure you use `SetCurrentProcessExplicitAppUserModelID` in the Rust setup for Windows targets so that system notifications have the correct App ID and show up properly.
